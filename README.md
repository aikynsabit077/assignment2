During this project, I learned how different algorithms behave in practice, not only in theory. At first, Bubble Sort seemed simple and understandable, but after testing it on larger arrays, it became clear that it is very slow. Quick Sort, on the other hand, showed much better performance, especially when the size of the array increased. This helped me better understand why algorithm complexity matters.
I also noticed that actual execution time can slightly differ from theoretical expectations because of factors like hardware and data distribution. However, overall results still followed Big-O predictions. Linear Search worked fine for small arrays, but it is not efficient for large datasets compared to more advanced searching algorithms.
One of the main challenges was correctly measuring time and organizing the code using classes. This project helped me improve my Java skills and understand how to structure programs using OOP.
